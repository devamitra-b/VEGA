# Contributing

Thanks for your interest in contributing to VegaThan / GlowGrid. Contributions are welcome — please use the following guidelines.

How to contribute
1. Fork the repository.
2. Create a new branch: `git checkout -b feat/my-feature`.
3. Make your changes with clear commits.
4. Open a Pull Request describing your changes and why.

PR requirements
- PR title and description must clearly explain the change.
- Include screenshots or sample logs for UI or firmware changes.
- Update docs when adding or changing firmware or dashboard behaviour.

Code style
- Keep firmware examples minimal and well-documented.
- Avoid including compiled binaries in the repo.

Issue reporting
- Open issues with reproduction steps and expected behavior.

License and CLA
- By contributing you accept that your contribution will be licensed under the project LICENSE (MIT by default).
